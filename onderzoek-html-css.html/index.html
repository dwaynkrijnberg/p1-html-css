Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

Webontwikkelaars gebruiken tegenwoordig de HTML Living Standard. Deze heet zo omdat HTML steeds wordt bijgewerkt en verbeterd. Er komen nieuwe functies bij en fouten worden opgelost, zonder dat er steeds een compleet nieuwe versie nodig is.

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

Webontwikkelaars spreken niet meer over één specifieke CSS-versie, omdat CSS is verdeeld in verschillende onderdelen die afzonderlijk worden bijgewerkt. Zo kunnen nieuwe functies worden toegevoegd zonder dat er een compleet nieuwe versie van CSS nodig is.

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Een website kan er anders uitzien in verschillende browsers, omdat Chrome, Firefox en Safari websites soms net iets anders weergeven. Ze gebruiken verschillende technieken en kunnen CSS en HTML iets anders verwerken. Ook kunnen lettertypes en standaardinstellingen verschillen.
